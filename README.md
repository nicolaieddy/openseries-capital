# OpenSeries Capital

Landing page for OpenSeries Capital (openseries.capital): the index fund for the private market, a US interval fund in development, designed to track the Morningstar PitchBook Global Unicorn Index.

One static page, no build step and no dependencies: `index.html`, `favicon.svg`, `apple-touch-icon.png`, `vercel.json`.

## Deploy

Vercel: import this repository (framework preset "Other", no build command, output directory `.`). Every push to `main` deploys.

## Contact form

Submissions post to FormSubmit (`ENDPOINT` in the script at the bottom of `index.html`) and arrive by email. The first submission triggers a one-time activation email to the receiving inbox; nothing is delivered until it is confirmed. After activation, FormSubmit offers a random alias to use in place of the address.

## Before the fund is offered

Fund counsel to review all copy, the comparison table and the footer notices.
