# OpenSeries Capital

Landing page for OpenSeries Capital: the OpenSeries Morningstar PitchBook Global Unicorn Index Fund, an index-based interval fund for venture-backed companies valued at $1 billion or more.

One static page, no build step and no dependencies: `index.html`, `favicon.svg`, `apple-touch-icon.png`, `vercel.json`.

## Deploy

Vercel: import this repository (framework preset "Other", no build command, output directory `.`). Every push to `main` deploys.

## Before publishing

- Replace every `[bracketed]` placeholder: fund name, ticker, fee, index name, platforms, launch date, minimum.
- Wire the request form in `index.html` (search for "Wire to the chosen form endpoint").
- Fund counsel to approve all copy, the comparison table and the footer disclosures.
